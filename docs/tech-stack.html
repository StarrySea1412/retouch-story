全部交互为浏览器内真实像素运算：直方图逐像素统计、通道缩放式白平衡、HSL 色相区间处理、径向合成局部光——确定性可复现，随时可回到直出。

诊断三问→二次构图→影调骨架→白平衡/HSL→局部光→风格与克制

01诊断

直方图三连问：曝没曝对 / 反差够不够 / 细节切没切 · 说意图 · 想代价——提阴影放噪点、拉饱和毁肤色，账单晚点到

02二次构图

裁剪是第一刀：视线留白 / 地平线 / 主体占比 · 裁剪=放大，画质在消耗 · 裁完的直方图才是有效直方图

03影调

曝光定基准 → 对比定骨架 → 高光/阴影分区找回细节 · 中间调目标带 110–130 · 顺序错了全白搭

04色彩

白平衡先归位，HSL 再站队 · 中性灰归位全图归位 · 治闷绿：降明度不是拉饱和 · 全局饱和度一根手指都不碰

05局部与风格

渐晕 15% 收视线、径向提亮给舞台（数字加/减光棒）· 色调分离是风格化最大杠杆 · 组片一致性 = 风格的复利

06克制

「修过但看不出来」是最高评价 · 三条停手判据（100% 放大 / 三天后再看 / 说得出理由）· 按输出尺寸锐化导出才闭环
